# Phase 1 requirements tracker

This is the active SDD v0.2 traceability register, expanded from the original
[v0.1 Phase 1 audit](phase1-requirements-audit.md). The v0.1 audit remains
historical and is not rewritten as if it covered v0.2. The register below
contains all 129 individually numbered requirement rows in SDD v0.2, including
their current delivery phase, accountable owner class, design anchor, test or
manual gate, evidence pointer, status, and explicit deferral/boundary. Status
is a repository-evidence snapshot and must be refreshed at release acceptance.
A test file existing alone does not mean Accepted.

Status meanings follow SDD §21.1: Not Started, Partial, Implemented, Accepted.
“Implemented” marks only the bounded behavior named by the cited evidence;
expanded requirements may remain partial. Proposed §19.2 budgets are unadopted.

The gallery-usability increment maps directly to FR-UX-001/002/006/007/010,
FR-MEDIA-001/003/004, and FR-JOB-001/003/004. It adds generated-fixture and
native evidence through [Task 21](tasks/21-gallery-usability-acceptance.md).
The Fedora/KDE identity is a derived release requirement anchored to SDD
§§15, 20–22; no identifier is invented for it.
